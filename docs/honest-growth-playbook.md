# Honest OSS growth playbook (DIY)

**Updated:** 2026-08-04

This is what a “GitHub growth” offer usually sells — rewritten as work **we do
ourselves**, without bots, fake stars, or paid vanity.

## What agencies promise vs what actually moves the needle

| Sales pitch | Real equivalent | Status / owner |
| --- | --- | --- |
| “Get real eyes on the repo” | Clear profile → hub → hero path; topics + descriptions | ✅ profile + hub + magnets |
| “Organic stars” | Value first, then ask once: install → proof → optional star | CTA in launch-assets |
| “Post in communities” | One useful post per channel with a **single** install CTA | drafts in `launch-assets.md` |
| “Feature in directories” | Maintain open PRs; no new spam during proof-loop freeze | awesome-mcp #9233 refreshed |
| “Influencer outreach” | Builder-to-builder asks to people who already engaged | jumpmanjay, maxgow, shkyyy18 |
| “Content marketing” | SOTA release notes + external tester stories | GH 0.7.2–0.7.3 / issue #21 |
| “Fake engagement” | **Never** | anti-list |

## Funnel (one sentence)

**Discover** (search, profile, hub) → **Install in 60s** → **Proof** (coverage /
demo) → **Contribute** (issue/PR/GFI) → **Star** only if it earned it.

## Weekly 30-minute loop (when capacity free)

1. External issues/PRs on hero + nourish (reply same day if possible).  
2. Proof-loop #21: still need **1 more independent** redacted coverage report by **2026-08-12**.  
3. One discovery fix: topics, broken link, stale pin, install path.  
4. **At most one** public post (X / LinkedIn / Reddit / HN) — never spray.  
5. No new connector “for marketing.”

## Metrics that count

| Metric | Why |
| --- | --- |
| External issues / PRs | Builder intent |
| Redacted coverage reports | Real-account proof |
| npm median daily downloads | Install intent (ignore spikes) |
| Stars on hero + hub | Discovery signal only |
| Inbound of weight (job / partner) | Authority probe success |

## Hard no

- Buying stars, bot follows, engagement pods  
- Mass directory spam while the proof loop is open  
- Paid growth without a success metric tied to **usage** (issues/PRs/installs)  
- Implying affiliation with Google / Fitbit / WHOOP / Garmin / etc.
