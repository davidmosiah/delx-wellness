# Honest growth playbook (OSS)

- Max **1 public CTA / week** (issue invite, README tip, or directory submission).
- **No** bot stars, purchased reviews, or fabricated metrics.
- Snapshot npm downloads + stars only from public APIs (`scripts/collect-growth-metrics.mjs`).
- Directory / awesome-list PRs require **explicit user OK** before opening.
- Coverage reports: real accounts only; booleans/errors preferred.

Cadence default: Monday review of open human issues on top5 OSS packages.
