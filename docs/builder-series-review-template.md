# Builder series review template

When reviewing a peer dense series tool:

- [ ] `contract_version` / agent-safe-series/v1
- [ ] `max_points` hard cap in schema
- [ ] stats computed on full-resolution samples
- [ ] honest `downsampled` / `method` / counts
- [ ] `coverage_anchor` when duration known
- [ ] zones `reference_source` if zones present
- [ ] no GPS/latlng in series tools
