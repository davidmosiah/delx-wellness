# Witness / external agent recurrence (no self-buy)

Proof loops need **external** humans or agents — not the maintainer buying their own stars/downloads.

1. Invite via open issues (`help wanted`) with redaction rules.
2. Accept only redacted coverage / install reports.
3. Never fabricate second coverage; if none arrives, publish honest `N/M` status.
4. Recurrence: re-open invite after each major release of the hero package.
