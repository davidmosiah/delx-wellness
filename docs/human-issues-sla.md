# Human issues SLA (top OSS)

**Target:** first human reply or triage within **48 hours** on issues/PRs from real humans on top packages.

Top packages: google-health-mcp, delx-wellness, wellness-nourish, whoop-mcp, creative-forge, garmin-mcp.

## Process
1. `gh issue list --repo davidmosiah/<pkg> --state open` (exclude bots).
2. Reply with next step, close as done, or label `waiting-external` naming the missing input.
3. Do not use bots to fake engagement.
4. Cross-ref: [community-response-sla.md](./community-response-sla.md).

This is a maintainer process, not automation.
