# Security Policy

Do not open public issues or pull requests that contain:

- OAuth access tokens or refresh tokens.
- Provider client secrets.
- API keys, database URLs, service-role keys, or private deployment secrets.
- Raw wearable exports from real users.
- Medical, psychological, or personally identifiable health documents.

If you discover a credential leak or privacy issue, contact the maintainer privately before posting details publicly.

These connectors expose user-authorized wellness context for AI agents. They are not medical devices and do not provide medical advice, diagnosis, treatment, or emergency support.
